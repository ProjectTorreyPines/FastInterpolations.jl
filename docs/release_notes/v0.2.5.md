## What's New

### DerivativeView Enhancements

- **Keyword forwarding**: Pass `search` and other keywords through derivative views
- **`AbstractDerivativeView`**: New abstract type for dispatch patterns
- **In-place vector support**: Efficient evaluation with pre-allocated buffers

```julia
d1 = deriv1(itp)
d1(xq; search=LinearBinary())   # Keyword forwarding works

# In-place evaluation (zero-allocation)
d1(out, xq)   
```

### Enhanced REPL Display

Interpolants now display rich, colored information in the REPL:

```julia
julia> cubic_interp(x, y; extrap=:extension)
CubicInterpolant{Float64}
├─ Grid:  Vector, 5 points ∈ [0, 4]
├─ Extrap: :extension
├─ Search: Binary
└─ BC:     ZeroCurv (S''=0 at ends)
```

### `Plots.jl` Recipe for Visualization

Visualize interpolants directly with the familiar Plots.jl interface:

```julia
using FastInterpolations, Plots

x = [0.0, 1.5, 2.0, 3.3, 4.0]
y = [0.0, 2.0, 1.0, 3.0, 0.5]
itp = cubic_interp(x, y; extrap=:extension)

plot(itp)  # Show plot with data points
```

📖 See details: [Visualization](https://projecttorreypines.github.io/FastInterpolations.jl/stable/visualization/)

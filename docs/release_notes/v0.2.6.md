## What's New

### 2-3× Faster Cubic Spline via Thomas Algorithm

The internal tridiagonal solver for cubic splines has been replaced with a specialized **Thomas Algorithm (TDMA)** implementation, delivering significant speedups:

| Mode | Before | After | Speedup |
|:-----|-------:|------:|:-------:|
| `autocache=true` | 1.46 μs | **0.49 μs** | **3.0×** |
| `autocache=false` | 2.69 μs | **1.22 μs** | **2.2×** |

Allocations reduced by **44%** (4.56 KiB → 2.56 KiB) for non-cached evaluation.

**No API changes**—existing code benefits automatically.

### Generalized `PolyFit` Boundary Conditions

New unified boundary condition system for estimating endpoint derivatives via polynomial fitting:

```julia
# Convenient aliases
bc = LinearFit()      # 2-point fit, O(h)
bc = QuadraticFit()   # 3-point fit, O(h²)
bc = CubicFit()       # 4-point fit, O(h³)

# Arbitrary degree
bc = PolyFit{4}()     # 5-point quartic fit
bc = PolyFit{D}()     # D+1 points, O(h^D)

# Mix boundary conditions
itp = cubic_interp(x, y; bc=BCPair(LinearFit(), CubicFit()))
```

| Degree | Implementation | Allocation |
|--------|----------------|------------|
| D=1,2,3 | Specialized kernel | **0 bytes** |
| D>3 | Generic barycentric | **0 bytes** (after warm-up) |

**Deprecation**: `ParabolaFit` → `QuadraticFit` (with deprecation warning).

📖 See details: [PointBC & PolyFit](https://projecttorreypines.github.io/FastInterpolations.jl/stable/boundary-conditions/pointbc)
